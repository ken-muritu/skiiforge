Teaching docs compiled from Pastor Charles Muchemi's sermon audio must read as if he is speaking/writing directly — "I," "we," "let me tell you" — never as a third-person report ("Pastor Charles said...", "he opened by...", "he pointed out that..."). The existing precedent doc in ~/Downloads, `God Gives Kingdom - Pst Charles Muchemi (Teaching).md`, is written entirely in first person and is the style to match — check it (or any prior compiled teaching doc) before drafting rather than defaulting to a reporting/narrator voice.

**Why:** On 2026-09-09, compiling "The Kingdom Life" teaching (two audios: the teaching + the "apart from teaching" context, per the user's instruction to treat both as one) I drafted the whole doc in third-person reporting voice despite having just read the first-person precedent doc moments earlier. The user caught it immediately: "you got this wrong, in the voice you wrote it...check logs again that's not how we did it... we want it in first person." Had to fully rewrite both the .md and regenerate the .pdf.

**How to apply:** Before drafting any compiled teaching doc, re-read a prior example in ~/Downloads (search for "Pst Charles Muchemi (Teaching)") and mirror its voice exactly, not just its section structure. When condensing spoken remarks (like pre-teaching context/banter) into prose, keep it in first person too — write it as the pastor's own recounting, not a narrator summarizing him. This pairs with [[feedback-audio-pipeline-no-default-split]] and [[reference-skiiforge]]'s audio-series-transcription-compilation skill — the skill's compile step should be understood to mean first-person compilation, not reporting.
