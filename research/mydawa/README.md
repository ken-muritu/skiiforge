## Capture method & constraints
- Only path to mydawa.com from this sandbox is the managed browser tool (direct
  fetch is egress-blocked; only GitHub/npm/Cloudflare allow-listed).
- That browser renders at a FIXED ~1512px desktop width with no device emulation,
  so genuine 390px/768px screenshots could not be produced (mobile/ tablet/ hold
  responsive documentation only). This is an honest limitation, not a skipped step.
- See metadata/capture-status.md for live status and the PENDING resume list.

## Safety
- No real purchase placed. No auth bypass. Only public, non-gated content captured.
